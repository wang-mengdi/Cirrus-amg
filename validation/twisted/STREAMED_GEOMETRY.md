# 流式生成并裁剪原生背景面

`makeEmbeddedOctree` 不再先保存完整背景面的数组。原生八叉树仍由
`makeOctreeChannel` 构造，叶单元的排序、编号和原生映射保持原样。
新增的可选参数允许嵌入边界导入延后生成面；其余调用保留原行为。

`SimpleMesh.cpp` 的 `visitFacesAndValidate` 按原来的单元、方向和
粗细子面顺序生成一个面，立即执行几何检查并交给回调。嵌入边界
回调查找原有 Aphros 开口记录，仅把实际流体面加入最终数组。
固体内部面经过检查后即被丢弃。壁面追加顺序、面积、中心、法向、
切割体积、周期偏移和粗细界面离散均未改变。

原来的 `validateMesh` 与新路径共用 `MeshValidation`：保留面所属
单元、法向、面积、距离、邻居、2:1 平衡和周期位移检查，以及六向
面积覆盖、Gauss 体积闭合、总体积和粗细面计数检查。阈值不变。
背景单元转移到局部 `Mesh`，同时保存覆盖与体积累加器，故仍有
随单元数量增长的临时内存；这不是整个导入过程恒定内存的实现。

## 真实流场回归与内存

CPU 16、GPU 16、GPU 64 各运行两个完整物理步，与上一版保存的
实际运行比较。网格、材料探针和构造检查输出逐字节一致。CPU 的
四个最终场 CSV 及每步保存的六个中间场 CSV 也逐字节一致。

GPU 的速度、压力、切割单元速度、壁面剪切向量和共享面通量，
最大相对 L2 差分别为 `3.059e-16`（16）和 `1.122e-14`（64），
通过原有 `1e-6` 回归门槛。完整固定点、实际单元通量平衡和截面
守恒检查均通过。新 GPU 64 完成 471 次线性求解，最大接受真实
相对残差 `9.962e-14`，低于保持不变的 `1e-13` 门槛。
