# Aphros 的阶段内存测量与按需零页存储

本次修改仅作用于 D 盘的隔离 Aphros 参考构建。Cirrus 原生八叉树、
几何、GPU 求解路径和精度门槛保持不变。参考中的完整网格尺寸、
曲面切割几何、字段索引、80 位扩展精度运算和原始投影/黏性/
对流/近壁离散函数体也保持不变。

## 实测问题位置

新增可选 Windows 工作集及私有内存采样，覆盖线性后端入口、
三元组组装、压缩矩阵、AMG 建立、求解、修正与原始方程检查。
采样构建在 16 网格上的六份最终输出逐字节一致，260 次外迭代
误差序列一致，精确面通量质量检查通过。

128 网格在进入线性后端时，工作集已为 10918408192 字节，
约 10.17 GiB；建立第一个 AMG 后约 11.26 GiB。它在首次压力
求解期间触发原有资源保护，未完成物理步。主要存储在进入
线性后端前就已经存在，因此仅继续缩减矩阵临时副本不够。

## 存储修改

`prepare_zero_page_reference.py` 复制验证过的隔离源代码，只修改
`geom/field.h` 的 `Vector` / `GField` 存储实现，并增加
`twisted_zero_pages.h`。完整重新编译全部 48 个翻译单元。

可选环境变量 `APHROS_TWISTED_ZERO_PAGES` 启用以下行为：

- 对至少 64 KiB、满足平凡构造/复制/析构条件的算术或向量字段，
  用 `VirtualAlloc` 保留完整连续地址空间和提交额度，按需分配
  物理页。其他类型继续使用原来的构造、复制和析构行为。
- 新数组明确初始化为正零时，保留系统提供的零值，无需遍历
  写入全部页。负零和 NaN 不会进入这条省略写入的路径。
- 复制时按 4096 字节块检查源表示，逐字节复制所有非零块。
  全零块的目标保持系统初始零值；尾页也完整处理。逻辑数组
  大小与内容不变，长双精度的表示及填充字节照样保存。
- 可变指针或元素访问会使“仍为初始零值”的标记失效。该标记
  使用原子操作，避免 OpenMP 的不同元素写入共享普通布尔变量。
  同一范围的 `Reinit` 仍保持原地址及已有外部别名的访问语义。

这里没有压缩数值精度、裁剪网格、修改矩阵系数或省略原始
方程残差检查。当前版本也没有在原地址取消提交并重新提交
已用过的字段；那是待验证的后续内存方案。

## 已通过的验证

独立存储测试在开关关闭、开启两种情况下均通过，覆盖负零、
NaN、部分尾页、标量和向量表示复制、移动、自复制、尺寸变化、
原地址清零、外部存储别名、非平凡对象生命周期和四线程写入。
测试探针中，两份 64 MiB 零数组的创建/复制使工作集从约
6.49 MB 增至 140.71 MB；开启后由约 5.24 MB 增至 72.35 MB。
该数值描述存储测试，不是整个 CFD 运行的内存下降比例。

按需零页版本的 16 网格第一物理步也通过完整原有比较器：

- 六份最终场及时间输出逐字节一致。
- 速度、压力、所有面速度和壁面剪切误差均为零。
- 260 次外迭代的打印误差序列相同。
- 精确通量复算质量相对 Linf 为 1.059271919161e-12。
- 原始方程函数体、实际构建对象、配置和原始几何的来源验证通过。
