# 按坐标行建立背景单元邻居索引

`simple/SimpleMesh.cpp` 的邻居查询现在使用 `(level,x,y)` 行索引。
原生八叉树单元本来按 `(level,x,y,z)` 排序；连续 z 行可直接计算单元
下标，有缺口的行使用二分查找。输入若为乱序，只建立排序后的整数
编号数组，保留调用方原来的单元编号与遍历顺序。

该实现替代原先每个背景单元对应一个哈希节点及桶的分配。没有修改
八叉树、加密掩码、曲面几何或求解算法。背景面的 owner/axis/child
遍历顺序、周期面、粗细交界、面几何公式、全部网格验证和 CSV 输出
代码段与原版本完全相同；独立范围检查在
`D:/CirrusExperiments/cirrus-amg/checks/row_cell_lookup_scope_v2`。
第一次范围检查因结束标记不够精确而失败，日志保留，随后修正检查脚本。

## 实际验证

同一测试程序分别链接旧哈希索引和新行索引，覆盖均匀/自适应、周期/
非周期、原顺序/倒序/随机顺序，以及 z 行有缺口的情况。两版各通过
37 个共同检查和 28 个流式遍历检查；48 份网格 CSV 逐字节相同。
重复单元、缺邻居、面积覆盖、Gauss 体积等非法网格仍被拒绝。

CPU 16、GPU full 16、自适应 GPU full 64 均实际完成两个物理步：

| 回归 | 结果 |
| --- | --- |
| CPU 16 | 最终及中间 CSV 逐字节相同 |
| GPU 16 | 五类场量最大相对 L2 差 `2.49432e-16` |
| GPU 64 | 五类场量最大相对 L2 差 `1.12371e-14` |

五类场量为速度、压力、切割单元速度、WSS 和共享面通量。原有实际
守恒、完整内迭代固定点和线性精度检查均通过，数值门槛未调整。
GPU 算子本身未改动。本次没有重复未受影响的 GPU 算子专门测试。

真实原生 128 构造于 2026-09-09 07:36:50 UTC 完成全部 39 个阶段，
六份网格、材质和算子初始化输出逐字节相同：

| 阶段的累计峰值工作集 | 改前 | 改后 |
| --- | --- | --- |
| 背景面计数后 | 1287274496 B | 1056710656 B |
| 流体面完成后 | 1681551360 B | 1450627072 B |
| 整个构造 | 2460975104 B | 2465165312 B |

流体面阶段累计峰值减少 230924288 B，约 220 MiB。整个构造的主导
峰值仍在后续算子阶段，实测增加约 0.17%，不能声称整个求解器内存
峰值降低。256 级完整流体导入和流动仍待验证；此前两次内存停止的
记录保留，64→128 空间收敛的失败项仍需解决。

随后已实现有界读缓冲校验，并在面构造前释放不再使用的参考单元
记录。单独构建、回归以及实际 256 完整导入结果见
[BOUNDED_GEOMETRY_LIFETIME.md](BOUNDED_GEOMETRY_LIFETIME.md)。
