# 保留压力迭代的小量更新，解除实际 RHS 的停滞

本轮在原 128 网格失败 RHS 上解除数值停滞：原单 double 迭代在
4000 次后仍约为 1.14e-13；保留补偿项后，三次测试均在 280 次达到
约 6.14e-14。线性门槛仍为 1e-13，Krylov 维数仍为 20。
这证明该失败 RHS 已能求解；完整 128 定常轨迹及空间验收尚未完成。

本文路径相对于 `D:/CirrusExperiments/cirrus-amg`。所有大规模算子
dump、构建和运行文件保留在 D 盘。

## 先分离算子误差与迭代误差

`NativeGpuConvergenceError` 现在保留被拒绝时的实际 GPU 迭代解及
最后一次用于判定的 Ax，均为归一化前后关系明确的双精度字节；
`rhs_scale` 记录原始 RHS 的缩放。失败解不会被当作成功结果使用。

仅在显式压力重放中，`dumpPressureFaces` 从 device 读回实际规则面
权重和局部粗细交界 stencil，导出 `CIRRUSP1` 二进制格式。它包含
2295544 个规则面、49152 个交界面及 2419168 个局部 stencil 项。
该导出是诊断用途，不改变 GPU 的原生 tile 存储或组装全局矩阵。

`native_pressure_arithmetic_oracle.cpp` 用 MinGW 的 long double
（实际 64 位尾数）独立按面计算 Ax；保持 device 上实际保存的
double 系数。它没有调用 GPU 求解器，也没有使用全局稀疏矩阵乘法。
规则面、交界面、消去误差和两部分输入的独立小例均通过。

单 double 失败迭代的结果为：

| 量 | 相对 RHS 的 L2 |
|---|---:|
| GPU 实际残差 | 1.1378774154e-13 |
| 高精度重新计算的残差 | 1.1379153629e-13 |
| GPU Ax 与高精度 Ax 的差 | 5.8024157436e-16 |

所以不能将这次停滞主要归因于面求和的误差。原迭代解归一化后的
范围约为 -16454～19399，而末期修正已经很小。本轮针对迭代更新
及其累积精度进行修正，而不是放宽接受门槛。

保留的单 double 状态在 `runs/pressure_failure_state128_v1`；最终
独立核对是 `checks/pressure_arithmetic128_v3/result.json`。

## 两部分压力迭代的实现

均值规范的压力 FGMRES 将解保存为两个 double 字段 `x + x_low`。
`updateKrylovTwofold` 使用显式乘积与 FMA 余项保留 Krylov 更新的
小量，用 TwoSum 形式合并到解中；均值消除也保留对应补偿项。
黏性求解及原来的 float AMG 预条件器保持原路径。

每次重新计算真实残差时，在 GPU 上分别计算 `A*x` 和 `A*x_low`，
相加后对照原 RHS。Krylov 基向量及 AMG 仍用原有精度。压力结果
接口返回 `values` 和 `lowValues`；缩放回物理量时保留乘法余项。

`ProjectionSolver` 明确接收两部分，在生成共享面压力梯度时都
使用它们，再修正实际存储的面通量。后续仍检查实际切割体积内的
守恒和完整固定点；没有以“两部分残差通过”豁免这些物理检查。
压力场本身仍按原物理状态格式保存，下一次线性调用从零开始；
不存在需要跨物理步保存的内部线性迭代历史。

`projection_method.json` 记录 `pressure_iterate_storage: twofold`。
本例额外 device 存储为 73764864 字节；未引入全局 GPU CSR 或 LU。
