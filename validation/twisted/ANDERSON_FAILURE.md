# 可选加速候选的线性失败与压力精度诊断

原 `ours_proj128_steady_original_rhs_v1` 在 dt=0.005 的第二个物理步
失败：FGMRES 在 4000 次迭代后的真实压力残差为 1.04809e-13，超过
配置的 1e-13。两次常规内迭代已经输出，而第二次加速候选尚未输出
接受记录。旧调用序列指向候选的固定点检查；它未记录调用阶段，不能
仅凭这项推断宣称具体失败阶段已被直接验证。

`anderson_failure_build_v1` 增加专门的 `NativeGpuConvergenceError`，
仅在真实残差未通过原容差时抛出。主物理求解、原始固定点检查、CUDA
错误和输入错误保持失败行为。只有 Anderson 可选候选内的该数值异常
会拒绝本次候选并尝试更小的步长；失败解不会返回或被接受。所有候选
被拒绝且其中发生线性失败时，恢复逐值复制的原速度、压力、黏性迭代
场和共享面通量，避免 pack/unpack 缩放造成二次舍入。

每次真实线性不收敛会保存 `linear_failure_N/failure.json` 与
`rhs.bin`，记录物理步、内迭代、调用阶段、候选序号、压力调用计数、
残差和原容差。右端为按网格单元 ID 排列的 little-endian float64。
候选失败另见该步的 `acceleration_linear_failures.csv`。

## 已完成的验证

- 16 和 64 网格的完整压力/黏性 GPU 算子检查通过。专门将一次求解
  限为一次迭代，确认产生上述数值异常，再复用同一个求解器正常求解；
  四项恢复后的真实残差均不超过 1e-13。恢复结果与失败前正常求解的
  最大绝对差不超过 2.665e-15。
- 16 网格的全部八个物理步、64 网格的一个物理步通过既有 CPU 对照
  检查，包括速度、压力、切割单元速度、壁面剪切、共享面流量、独立
  守恒重算及原真实线性容差。16 网格最终 t=0.008 的独立 Aphros
  对照也全部通过。
- 新旧 GPU 二进制的 16 网格逐位比较未通过。检查的第一步及第八步
  速度/压力最大绝对差在 1e-18 至 2e-17 量级，正常路径的物理步和
  内迭代次数相同。保留未通过的逐位检查；不能将数值接近写成逐位一致。

实际 128 网格 dt=0.005 的两步复现在
`output/twisted/ours_proj128_anderson_failure_2steps_v1`。本检查点建立
时该运行仍在推进，尚未证明原候选失败已经复现或两步全部通过。
完整 128 定常结果仍缺失，物理网格与时间步收敛也仍待完成。

## 全耦合压力的扩展精度重放

此前局部试算固定相邻压力，不能证明全耦合压力系统可通过守恒门槛。
本次从完成的原始 Aphros 64 面表达式捕获中，构造 140216 个流体单元
与 409364 个唯一共享面的完整周期图。原始几何、e0/e1/b 系数和初始
压力均以原 double 值读入，没有改写已有参考流场。

`pressure_coupled_precision_probe.cpp` 用 MinGW 的 64 位有效尾数
long double 保留压力及原 `p0*e0+p1*e1+b` 的计算顺序。double AMG/CG
仅提供压力修正，是否接受由重新计算的全图面守恒决定；没有修改面
表达式或对最终通量作再分配。

初始扩展精度重算的最大相对散度为 2.638397619e-7。一次全图修正后
为 6.611696828e-11，修正系统使用 24 次 CG 迭代。导出的压力以十六
进制保留全部二进制位；独立 Python 检查用 100 位 Decimal 重算全部
面表达式，最大相对散度为 9.271919109e-11。除去压力零点后，压力
相对原字段的最大绝对变化为 2.109885682e-16。

这证明该捕获压力状态可以通过扩展精度恢复全图守恒。它仍是离线压力
实验，没有构建新的完整 Aphros 流动轨迹，不能作为曲管定常速度、
压力、近壁量或网格收敛已对齐的证据。原 Aphros 长算例继续使用原
二进制，未停止、覆盖或重新启动。
