# 稀疏开放面查找表

`simple/EmbeddedOperators.cpp` 原来按整个最细笛卡尔背景盒分配
`3 * nx * (ny+1) * (nz+1)` 个 int32，用于区分有效采样面和被排除的面。
实际管道只占背景盒的一部分。`simple/OpenFaceLookup.h` 保持原线性键，
按 `(axis,x,y)` 分行，只储存存在的 `(z,face_id)`，通过行内二分查找读取。

构造时两次重放同一不可变的面序列：计数、精确预分配并写入。每行按
`z` 稳定排序；重复键保留最后赋值，包含最后 face ID 小于先前 ID 的
情况。不存在或超出逻辑范围的键返回 `-1`。计数不一致、非法键和面
编号仍拒绝。构造结束释放计数游标；所有面和重分配算子构造后释放
查找表，与此前相同。

单元选择、键坐标及取整、周期 x 索引、被排除面零延拓、壁面拟合、
粗细交界二次重构、插值、梯度、黏性和重分配公式保持不变。代价是
多一次面序列扫描和行内搜索，换取稀疏背景盒的存储下降。

## 索引验证

从已逐字节验证的完整原生 256 网格 CSV，按旧实现的选择和键公式
生成 10045128 次面赋值，保持原面 ID 顺序。读取全部 12263704 个面。
最大坐标取整偏差为 `2.2737367544323206e-13`，没有取整中点歧义。

独立 C++ 测试对全部 101451264 个逻辑槽位逐一比较旧稠密表与新表，
全部一致，包括不存在采样面的槽位。另验证空表、空行、单列、乱序、
重复键最后赋值和 6 类非法输入。实际数组容量：

| 原稠密表 | 新稀疏表 | 减少 |
| --- | --- | --- |
| 405805056 B | 83519048 B | 322286008 B（约 307 MiB） |

这是该查找表的数组存储，不是求解进程整体峰值。

1536 个粗细交界面。

2026-09-09 10:49:49 UTC 完成。CPU 最终及内迭代 CSV 逐字节一致。

这组回归比较新旧 Cirrus 实现，确认存储修改不改变已有结果；
不能替代独立 Aphros 对齐或更细网格空间收敛检查。
