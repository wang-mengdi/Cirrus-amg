## 面表达式和可表示精度

64 的只读面表达式捕获在 39 次原始外迭代后结束。保存的原表达式
`p0*e0+p1*e1+b` 能逐位复算所有最终面通量。

在保持保存压力不变的离线诊断中，改用压力差形式后的最大相对散度
为 2.623521301e-7；使用 Decimal 精确乘积再舍入一次为
2.637736450e-7。体积均值压力零点、最小体积单元压力零点也未通过。
这些都是内存中的假设计算，没有替换任何原始参考场。

最小单元体积约 5.079e-18，约为完整立方体的 6.82e-10。其压力约
1e-2，double 相邻可表示数的间隔为 1.735e-18。原行对角系数求和的
舍入差为 1.654e-24，乘以压力后已与目标净流量误差同量级。在保持
相邻压力不变的单元试算中，部分最差单元附近的可表示 double 压力
均无法达到当前局部守恒门槛。这不证明整个耦合系统无解。

用相同捕获系数和固定相邻压力进行 C++ 扩展精度局部试算，MinGW
GCC 13.2 的 long double 具有 64 位二进制有效尾数（double 为 53 位）。
12 个最差单元的局部扩展精度根均通过门槛，最大相对散度约
9.918e-11。该实验没有解耦合压力系统，也没有生成新参考流场。首次
动态链接试算在执行时崩溃；保留失败文件，使用静态运行库重新构建后
完成上述检查。

进一步在独立目录中编译了原始 `MeshCartesian<long double,3>` 与
`Proj<Embed<MeshCartesian<long double,3>>>`。仅补充 long-double NaN
支持、将通量/出口限制中的精确零常量写成对应 Scal 类型，并使用原
构建的 M_PI 常量；原投影、黏性与对流表达式没有修改。两个目标文件
编译通过。该结果仍只是类型兼容性证明：完整程序的链接、执行、
原始几何保持、线性求解精度与完整流场对照尚未完成。所有改动都在
新目录内，既有参考库和仍在运行的任务未被覆盖。

## 压力方程与 matrix-free 的实现边界

`ProjectionSolver::project` 中的线性系统是压力投影的 Poisson 方程，
当前增量校正求解的是压力冲量修正。另一个线性系统来自隐式黏性
扩散，含有质量项。两者写作 `Ax=b` 都不要求显式存储全局矩阵。

`linear_backend=native_gpu` 时，`NativeCompactGpu::applyDevice` 从原生
八叉树 tile 邻居、面权重和局部切割/粗细接口模板计算算子作用；
FGMRES 使用原生 Cirrus FAS 周期作为 AMG 预条件器，没有 GPU 全局
CSR 装配或 LU/LDLT 分解。局部模板系数、网格连接和多重网格层级仍需
存储，matrix-free 不等于不保存任何系数。

CPU 对照路径保留显式稀疏矩阵，可选择 LDLT 或 AMG。当前 GPU 版本的
CPU 初始化、输运和部分外围运算也仍保留显式稀疏算子。因此准确范围
是 GPU 线性求解采用 matrix-free；整个程序尚未完全取消矩阵装配。
同一离散方程的精度对齐不要求使用与 CPU 基线相同的线性求解后端。
