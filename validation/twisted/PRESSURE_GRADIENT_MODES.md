# 压力时间步差异与弱梯度模式

对已经完成的 16 网格定常结果做离线诊断，压力时间步差异没有主要
集中在本次定义的弱梯度模式中。该结果缩小排查范围，尚未修正时间步
敏感性，也不替代 64 网格时间步减半实验。

使用此前已经验证过的真实离散单元梯度 Gc，以及全部开口共享面的
两单元梯度。对任意压力向量 p，定义两种能量：

```text
Ec(p) = sum_c Vc |Gc p|²
Ef(p) = sum_f (Af / df) (p_neighbor - p_owner)²
```

广义特征值 lambda = Ec / Ef 较小时，单元梯度对该模式的响应相对
面梯度较弱。两者共同的常数压力自由度通过固定一个单元消除。
计算了 2744 个流体单元对应的全部 2743 个非恒定广义模式，最小
特征值约为 0.000977252；本次数值谱没有发现额外的零模式。
改为固定体积最大的另一单元，最低 64 个特征值的最大变化为
9.93e-13。常数梯度、特征方程残差及能量内积正交性检查均通过。

使用体积加权正交投影，测量实际压力差在弱模式子空间中的能量
占比。该投影采用 sum(Vc * delta_p²) 内积，与定义特征模式所用
的面梯度内积区分；没有把不同内积下的系数平方直接相加。

| 模式定义 | 模式数 | dt=5→2.5 ms 的压力差能量占比 |
|---|---:|---:|
| lambda < 0.01 | 72 | 0.03093% |
| lambda < 0.05 | 251 | 0.51145% |
| lambda < 0.10 | 423 | 1.19273% |

这一对来自同一个可执行文件、相同 Anderson 设置，压力相对 L2
差为此前记录的 0.47822%。该压力差自身的 Ec/Ef 为 0.45950，
而较小时间步最终压力的 Ec/Ef 为 0.98855。

后两次时间步减半中，lambda < 0.10 子空间的占比分别为 2.74392%
和 5.80879%。它们涉及不同历史构建或 Anderson 设置，保留为诊断，
不作为只改变时间步的受控实验。所有运行均已达到原来的定常标准；
原先时间步敏感性未通过的结论不变。

这些数据不支持把压力变化主要归因于上述弱梯度模式，也不支持
直接增加压力滤波来“修正”结果。它们没有排除一般压力—速度耦合
误差，也没有单独区分近壁重构、BCG 输运和投影时间步项的贡献。
继续以完整 64 网格减半实验和对应离散更新作为下一步判断依据。
