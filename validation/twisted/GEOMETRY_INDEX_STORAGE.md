# 连续存储的参考几何索引

`simple/EmbeddedMesh.cpp` 将只读参考几何的三棵查找树改为连续数组：
每项保存整数坐标键和 32 位原始记录行号，排序后用二分查找访问
原始 double 数据。超过行号容量的输入会明确报错。还用按参考
单元行号寻址的整数数组保存原生细单元映射，并转移背景单元数组
的所有权，避免复制整份背景单元。

切割体积、面心、面积、壁面法向及粗细界面几何均未重算。相同键
按原始行号排序，再保留首次出现的记录，延续旧 `map::emplace`
语义。单元体积累加和壁面追加仍按键的字典序进行，以保持浮点
累加顺序和输出面编号。重复单元检查、周期面面积检查、缺失细
壁面单元检查以及原有几何闭合检查均保留。
