# Aphros 直接线性后端的完整场与资源试验

本项尝试缩短独立 Aphros 参考计算的时间。使用已编译在同一
验证执行文件中的 AMG 和直接线性后端，完整保留原 Aphros
投影、对流、黏性更新、几何、物性及原方程残差检查。
Cirrus 的原生八叉树和 GPU matrix-free 算子没有改动。

## 资源观测

`profile_aphros_backend_pair.py` 核实实际完成状态、相同执行文件、
配置、几何和除后端外相同的环境。它检查内存 trace 的事件序列，
分别统计准备、第一次线性求解、迭代修正及原始行检查阶段。
该报告只解释资源使用，不代替场值验证。

| 网格/后端 | 总耗时（秒） | 峰值工作集（字节） | 完整线性调用 |
|---|---:|---:|---:|
| 16 AMG | 46.26 | 67076096 | 1560 |
| 16 直接 | 42.77 | 43520000 | 1560 |
| 32 AMG | 336.61 | 249098240 | 1107 |
| 32 直接 | 135.30 | 360816640 | 1107 |

32 网格中，线性后端累计耗时从 276.88 秒降到 75.31 秒，准备
开销则从 16.63 秒增加到 33.86 秒。观测总耗时比约为 2.49。
Windows tick 计时有量化误差，且其他计算同时运行；这些数值
不是独占硬件基准，不能外推成 64/128 网格的性能保证。
