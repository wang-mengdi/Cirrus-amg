# 在 D 盘运行带初始速度的低内存 Aphros 参考

新增 `scripts/run_aphros_seeded_reference.py`，把已经分别验证过的
速度初值加载、单份算子缓存、冷存储释放和按公式计算网格中心组合
在一次实际参考运行中。输出目录必须在 D 盘，且必须是新目录。
原始 Aphros 的 Proj 方程、几何、浮点类型和线性 AMG 设置保留。
这项调整只作用于 CPU 参考运行，不修改 Cirrus 的 GPU 求解路径。

运行器核对实际构建源、执行文件、初值文件、几何和配置的哈希，
记录实际子进程身份、时间和内存；执行结束后再次检查输入和实际
初值读回。系统可用内存连续 10 秒低于 2.5 GiB 时，仅停止本次新
启动且身份已核实的 CPU 子进程，并把结果记为失败。
