# 为较细 Aphros 参考准备可追溯初值

`scripts/prepare_aphros_initial_velocity.py` 现在显式支持从完整验证过的
原生定常迭代结果准备**仅含速度的初始猜测**。使用
`--kind native --native-steady-iteration`；缺少显式选项、使用未达到
定常的输出或不完整的定常运行都会被拒绝。源运行需通过原始方程、
完整内迭代、实际八叉树连接、GPU 原始残差、原始 dump 及守恒检查。
检查证明另存为 `native_steady_source_check.json`。

它不会把压力、共享面通量或物理时间从 Cirrus 恢复到 Aphros。
Aphros 仍需要从该速度初值执行自己的原始投影方程，最后单独验收。
初值清单明确保持 `only_velocity_initialized: true` 和
`steady_alignment_proven: false`。
