# 周期边界的 AMG ghost 覆盖

256 级扭曲细管在 GPU 场量初始化后，原生 AMG 面系数装配报错：
`Native AMG missing a required face/ghost tile`。完整的逐面诊断检查
3995168 个流体单元及 12263704 个面，发现 192 个缺失面，全部位于
x 周期缝的细到粗连接上。它们要求的 AMG Tile 分别是
`(level=5,x=0,y=20,z=15)`、`(5,0,22,19)`、`(5,0,22,20)`，
每个对应 64 个面；所有面都有正确的粗层流体父单元。

例如面 11906782 的细层 owner 坐标是 `(511,160,120)`，粗层
neighbor 是 `(0,80,60)`。正 x 面需要细层 `(512,160,120)`，
周期映射后成为 `(0,160,120)`，对应的 ghost Tile 缺失。
原生 `HAGrid::spawnGhostTiles` 使用非周期邻居坐标，而 AMG 的
面查找会先执行 x 周期映射。周期缝两侧的加密层级不同，就暴露
了这处覆盖缺口。16 和 64 网格的原始逐面检查没有缺失。

`simple/NativeAmgTopology.h` 对 AMG 自己的层级补齐周期 ghost：
从细层向粗层枚举周期边界上的活跃 Tile，检查另一侧的同层邻居。
若缺少邻居，只有存在相应粗层叶子时才能新增 ghost；无合法父
单元的情况明确拒绝。x 的两个方向都处理，因为粗到细连接虽然
把面系数存在现有细叶子上，AMG 运算仍需要另一侧 ghost。

调用点位于 `NativeAmgPreconditioner.cu` 建立祖先之后、填充单元
类型和面系数之前。新增 ghost 继续使用原来的父单元掩码、系数
汇聚、对角元和 FAS 运算。原物理网格、现有 Tile、离散面、壁面
及控制体积不变。此次修复不改动原生网格类的全局行为。

## 验证入口

`validation/native_amg_topology_test.cpp` 的 12 项检查覆盖两侧周期
缝、多层结构、已有 Tile 保持、重复调用，以及非法父单元和尺寸
的拒绝。实际测试通过。

`native_compact_gpu_audit` 新增两种独立诊断配置：

- `audit_amg_topology_only: true`：枚举每个物理面所需的 AMG Tile；
  使用 `audit_complete_periodic_ghosts: true` 检查修复后的覆盖。
- `audit_amg_compact_only: true`：先检查上述拓扑，再实际求解压力
  和隐式黏性制造解，使用独立 CPU 守恒面循环核验。原门槛保持为
  GPU 真实残差 `1e-13`、CPU 相对残差 `1e-12`、解相对 L2 `1e-8`。

拓扑输出包含完整 Tile 列表、全部缺失面及代表性坐标。制造解
输出包含每个单元的已知解、右端项、GPU 高低位解和 CPU 残差。
这些属于线性算子验证，不能替代完整曲面离散的流动、独立 Aphros
比较或空间收敛验收。所有大型输出保留在 D 盘。
