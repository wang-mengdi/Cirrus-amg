## 实现及边界

`scripts/twisted_prefix_restart.py` 定义
`cirrus_projection_prefix_restart_v2`。它保存每个单元的
`u,v,w,p,u_diff,v_diff,w_diff` 和所有面通量，按原 ID 顺序写入
little-endian float64。恢复字段来自实际最后一次未加速迭代的
dump，重新读取后必须逐字节相等。

检查器验证实际执行文件、配置、几何和每个已完成步的文件哈希；
对保留完整场的步，从全部共享面通量独立复算质量守恒。
完整内迭代固定点和隐式黏性残差必须小于 1e-8，质量相对 Linf
必须小于 1e-7，GPU 实际线性残差及兼容性检查仍不超过 1e-13。
这些门槛没有因恢复而降低。

父运行日志中更晚物理步开始的记录是输出已写完的屏障。
运行、时间及 GPU 日志只捕获完整行的前缀，重新检查时必须仍是
原日志的前缀；它们不冒充整个父运行的成功结束记录。
若没有更晚一步的屏障，则必须有真实成功的终止与完整步数证明。
GPU 捕获可能含选定步之后的调用，报告明确标明这一范围。
线性失败记录只能作为已拒绝尝试保留，不能接受其解。

当前父运行必须从零启动，不支持恢复链。SIMPLE/投影物理参数、
网格、时间步和误差门槛必须一致；v2 仅额外允许在已验证的
MGS2 与 CGS2 正交化间切换。它们使用同一个原生隐式算子和
相同实际残差门槛。原 v1 恢复格式保持原来的限制。

`simple/ProjectionSolver.cpp` 接受 v2，并检查实际状态尺寸、
时间和配置；原有状态恢复及 `restart_loaded.bin` 回写仍使用。
此次没有更改 GPU 压力/黏性算子，也没有加入全矩阵分解。
Python 包装器先完成证据验证，再复制前缀、启动程序；验收时
检查实际 C++ 回写、前缀副本、重建网格和所有新时间步。
