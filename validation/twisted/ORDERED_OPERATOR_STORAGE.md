# 直接填充稀疏算子并释放组装临时数据

上一轮阶段测量显示，64 扭曲管的曲面算子组装会同时保留组装行、
三元组、Eigen 转换工作区及最终矩阵。本次只改动
`simple/EmbeddedOperators.cpp` 的存储构造和临时数据生命周期。

`Row` 已按列号排序并合并重复系数，系数累加顺序不变。转换函数
先统计非零项，检查其数量不超过稀疏存储索引容量，再精确预留
最终行主序存储，通过 `startVec`、`insertBack`、`finalize` 依序
写入。保留原来的零项过滤规则，不再创建全局三元组数组，也不
经过 `setFromTriplets` 的中间转换。操作语义核对了本机 Eigen
的实际 `SparseMatrix.h` 实现，并以完整系数输出验证。

每个最终矩阵拥有系数后，立即销毁不再使用的组装行。面梯度
组装行继续保留，供三个方向的单元梯度按原顺序累加。全部面和
重分布行构造完成后，释放几何查找表、开口面索引、切割单元邻域
及壁面法向临时数组；完整黏性矩阵仅保留到延迟项矩阵生成结束。
显式动量分支也释放不使用的紧致组装行。

没有修改原生八叉树、曲面几何、壁面闭合、粗细交界重构、重分布、
求解选项或 GPU 算法。CPU 稀疏算子仍服务于现有输运及诊断路径；
此改动没有把它们接入 GPU 线性求解。

## 实际验证

旧版 `builds/construction_memory_v2` 与新版
`builds/ordered_operator_storage_v1` 的源快照只有
`simple/EmbeddedOperators.cpp` 不同。Windows 主程序和 GPU
审计目标均编译通过，新主程序 SHA-256：
`b03af4f31f7a2ed192223eb1d91539be065def53e152d7592f3cc6f42273e568`。

直接运行两版生产程序，导出并比较全部算子矩阵系数：

| 配置 | 算子矩阵数 | 实际粗细交界面数 |
| --- | ---: | ---: |
| uniform 16，隐式动量，无对流 | 9 | 0 |
| uniform 16，隐式动量，有对流 | 10 | 0 |
| uniform 16，显式动量，有对流 | 10 | 0 |
| adaptive 64，隐式动量，有对流 | 10 | 1536 |

39 个完整算子矩阵均逐字节一致，相关网格、矩阵形状及解析算子
检查也一致。覆盖面插值、面和壁面梯度、紧致及延迟黏性、重分布、
三个单元梯度和对流面插值，不仅比较残差或几个探针。

首次测试脚本还请求了“显式动量、无对流”组合，被旧版已有选项
检查在构造前拒绝。该失败保留在 `ordered_operator_coefficients_v1`；
最终 `v2` 使用上表所有有效组合，没有修改该选项检查。

另用旧版已保存的实际流场作对照，新版 CPU 16、GPU 16 和 GPU 64
各运行两物理步。GPU 采用相同完整压力/黏性及严格线性残差设置，
比较速度、压力、切割单元速度、壁面剪切向量和共享面通量，并
执行已有固定点及质量守恒检查。结果保存在本目录的小型证据中；
完整实验均位于 D 盘。

三组两步回归通过。CPU 最终四份场/通量 CSV 和每步六份中间
CSV 逐字节一致。GPU 16 和 64 的五类场量最大相对 L2 差分别
为 `2.331e-16` 和 `1.114e-14`，保持原有 `1e-6` 门槛。
新 GPU 64 完成 473 次线性求解，最大接受真实相对残差
`9.962e-14`，仍满足 `1e-13` 门槛。

## 实测内存与后续范围

64 的构造阶段 Windows 累计峰值工作集，MiB：

| 阶段 | 旧版 | 新版 |
| --- | ---: | ---: |
| 曲面算子构造结束 | 579.41 | 446.48 |
| 完整 projection 初始化结束 | 579.41 | 527.32 |

曲面算子构造峰值下降约 22.9%，整个初始化的峰值下降约 9.0%。
这些是同一实际算例的进程观测；Windows 分配器和并行运行环境
会影响读数，不能把差值精确归因到单个数组。完整流动的峰值可能
出现在后续迭代，不能以初始化峰值代替。
本次完整两步 GPU 64 峰值工作集由 730.43 变为 728.26 MiB，
变化约 0.3%，没有观察到完整求解峰值的明显下降。

本轮没有执行原生 128/256 的新版构造或流场，不能据此宣称更细
网格已满足内存条件，也没有新增定常、Aphros 对齐或空间收敛
结论。64→128 的近壁速度及壁面剪切失败仍待解决。下一步应
针对剩余实际峰值继续减少冗余存储，再完成更细网格的精度检查。
