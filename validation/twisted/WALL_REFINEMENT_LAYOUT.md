# 更细壁面网格的布局预估

实际 64→128 定常比较尚未通过近壁精度验收，见
[空间检查](SPATIAL_CONVERGENCE_64_128.md)。本次先估算保留当前壁面
最细分辨率及两格缓冲时，多层八叉树能节省多少单元。没有生成新的
256/512 原生网格，也没有运行这些分辨率的流动。

`scripts/profile_twisted_refinement_layout.py` 逐个 x 截面计算解析管壁
在网格顶点的符号，以八个顶点判定流体和切割单元。它只保留相邻
两个顶点截面以及 tile 计数，避免分配完整三维符号场。壁面加密
掩码沿用导入器的两格缓冲；多层预估使用 26 邻域的保守 2:1 平衡。
预测的物理叶 tile 不含原生 ghost、父层和 AMG 存储。

## 用已经完成的 128 网格核对

输入是 `steady_outer128_v1` 的完整定常状态检查及其原始几何。
预估器实际核对了全部 87,248 个切割单元 ID、440 个被加密的根
tile、4,104 个物理叶 tile，以及各层的流体单元数：粗层 40,960，
细层 749,256，总计 790,216。均与真实原生网格一致。

这证明该分类器在这份几何和分辨率上的计数正确，不能替代更细
网格的实际拓扑构造与算子检查。原生 128 共分配 6,264 个 tile，
大于上述物理叶 tile 数；不能直接把叶 tile 预估当作全部分配。

## 预测规模及其意义

| 最细 ny | 基础 ny | 物理叶 tile | 流体单元 | 切割壁面单元 |
| --- | --- | ---: | ---: | ---: |
| 128 | 64，现有一级加密 | 4,104 | 790,216 | 87,248 |
| 128 | 32，多层预估 | 4,104 | 790,216 | 87,248 |
| 256 | 128，一级加密预估 | 20,120 | 3,995,168 | 349,008 |
| 256 | 64，多层预估 | 17,936 | 3,966,496 | 349,008 |
| 512 | 256，一级加密预估 | 112,968 | 20,767,624 | 1,395,720 |
| 512 | 64，多层预估 | 73,936 | 17,957,768 | 1,395,720 |

256 的多层布局减少 10.85% 物理叶 tile，却只减少 0.718% 流体单元；
最细层流体单元仍为 3,360,288。因此，多层加密对该分辨率的流体
状态存储帮助很小。512 对应减少 34.55% 叶 tile、13.53% 流体单元，
但仍有约 1,796 万流体单元。将基础 ny 从 64 降到 32，在本次保守
平衡规则下不再减少物理叶 tile 或流体单元。

报告同时列出两个存储量：每个叶 tile 的 double 标量槽数为 736；
FGMRES 的 basis 和 images 已按流体单元紧凑存储，维度 20 时共为
41 个 double 向量。256 多层预估仅这组 Krylov 向量就需要
1,301,010,688 字节；512 为 5,890,147,904 字节。这些量不包括原生
父/ghost tile、其他工作向量、AMG、面模板、CPU 算子和迭代历史，
不能据此声称完整实验能放入当前内存或显存。

当前生产代码的嵌入网格导入只支持一级加密。原生八叉树基础设施
能表达更多层，但本次没有修改生产网格接口或求解算法。依据这里
的收益预估，后续应先处理实际求解状态与构造临时对象的内存占用，
再决定是否为 256 引入多层嵌入网格。

## 复现和存储位置

```powershell
python scripts/profile_twisted_refinement_layout.py `
  --geometry C:/Code/Cirrus-amg/output/twisted/packed_n128/geometry.json `
  --native-state-check D:/CirrusExperiments/cirrus-amg/configs/initial_velocity128_native_steady_v1/native_steady_source_check.json `
  --output D:/CirrusExperiments/cirrus-amg/checks/<新目录>
```

实际重跑输出位于
`D:/CirrusExperiments/cirrus-amg/checks/wall_refinement_layout_forecast_v2`，
退出码为 0；同级 `.log` 保留运行输出。报告记录所读实际网格、
几何、检查结果和相关源码的 SHA-256，并在结束时确认输入未变。
提交中的小型证据在 `results/wall_refinement_layout`；大体积实验、
构建和 dump 继续留在 D 盘。原始 Aphros 128 对照仍在独立计算，
本布局预估不改变空间验收失败，也不构成独立流场对齐结论。
