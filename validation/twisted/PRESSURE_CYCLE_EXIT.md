# 增加有界的压力舍入循环退出

本轮保留原来的相邻散度相等退出条件，增加一个更严格的周期
判断。它只适用于原生 GPU 的均值规范压力投影：必须完整观察到
两遍长度为 2、3 或 4 的非恒定散度周期，并且整个窗口内的速度
和压力冲量修正都小于相应修正后物理尺度的半个 double epsilon。
任何大修正、非有限值或越界散度都会打断有效窗口。

每条观测的原始散度仍须在 [1e-10,1e-8]，退出前另用补偿求和
检查实际共享面通量，绝对散度不得超过 1e-8。最终完整固定点、
黏性和相对连续性检查保持原门槛；线性求解仍须满足 1e-13。
没有删除小体积单元、修改通量以掩盖失衡或加入全局 GPU 矩阵。

`simple/PressureRoundoffCycle.h` 保存最多 8 条观测，只属于一次
投影调用。`ProjectionSolver.cpp` 记录实际修正后的尺度；新的
压力冲量界包含 twofold 返回值的高、低两部分，并向上舍入。
原有标量退出仍写 `projection_roundoff_exits.csv`；周期退出单独
写 `projection_cycle_exits.csv`，包含导致决定的完整两遍观测。

## 实际 128 预测通量重放

为触发并检查新分支，增加显式 `operator_only` 诊断：

```json

"projection_replay": {
  "predictor_state": "D:/CirrusExperiments/cirrus-amg/checks/prefix_restart128_step12_v2/state.bin",
  "repetitions": 3

```

程序从已验证的完整步 12 状态读取速度、压力和通量，以原 BCG
预测及加速度代码重建下一步首个预测通量。完整 BCG 时间步为
0.005，投影时间尺度为 0.0025，初始压力冲量为零，与实际
`predictedFlux()` 调用一致。两种退出规则读取同一份投影前通量，

另支持直接读取 `flux` 二进制的诊断，且与 `predictor_state`
互斥。14 个非法模式检查都在网格/GPU 构建前拒绝了输入。

直接返回；已经投影后的半步 dump 完成了 24 次线性求解，但
没有触发周期退出。这些均不作为新分支的通过证据。
