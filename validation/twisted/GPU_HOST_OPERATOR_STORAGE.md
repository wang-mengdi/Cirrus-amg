# GPU 投影分支的主机算子存储

GPU 的 matrix-free 压力/黏性算子及原生 AMG 没有修改。本次只调整
`simple/ProjectionSolver.cpp` 中主机侧常量矩阵的生命周期，降低
更细八叉树算例的内存开销。

压力矩阵仍用于初始化时选择压力基准单元、检查粗细交界和材料
插值。GPU 分支完成这些步骤后，实际压力校正通过面梯度和共享
面通量执行，压力重放的 CPU 核对也使用散度/面梯度。因此释放
随后不再使用的主机紧致压力矩阵和压力延迟矩阵，保留散度及面
梯度。CPU 分支继续保留原矩阵和原线性求解路径。

GPU 完整黏性模式的隐式求解使用原有 GPU 面算子；主机动量及
固定点残差仅需要 `diffusionMatrix + diffusionDeferred`。本次
在材料检查之后以相同 Eigen 系数加法生成该常量和，释放两个
独立输入，后续残差使用这个合并矩阵。显式零项也保留。
GPU 紧致黏性模式仍保留紧致/延迟分解，继续原来的延迟修正。

需要纠正前期的内存判断：实际 Eigen 5.0.1 对这里的列优先
三列速度场采用惰性稀疏和，没有每次物化完整临时矩阵。
编译类型探针确认 `nested_eval` 不物化该和。新实现节省的是
长期保存的重复系数及反复迭代合并两个输入的工作，不能把收益
归因于删除一个不存在的逐次完整临时矩阵。

## 已完成流动回归

比较构建 `ordered_projection_storage_v1` 与
`gpu_host_operator_storage_v1`，每组均从零开始推进两个实际物理
步。构建源中仅 `ProjectionSolver.cpp` 改变；独立 GPU 审计程序
SHA-256 保持完全相同。实际几何、配置、线性残差、完整固定点
及存储面通量的守恒门槛保持不变。

| 回归 | 结果 |
| --- | --- |
| CPU 16 | 每步四份最终 CSV 及六份中间 CSV 逐字节相同 |
| GPU 完整黏性 16 | 五类场量最大相对 L2 差 `3.1179e-16`；132 次线性调用 |
| GPU 完整黏性、自适应 64 | 五类场量最大相对 L2 差 `1.1106e-14`；470 次线性调用 |
| GPU 紧致黏性 16 | 两步五类场量相对 L2 差为零，完整固定点及守恒通过 |

五类量为速度、压力、切割单元速度、壁面剪切和共享面通量。
完整黏性 16/64 的最大实际 GPU 相对线性残差分别为
`9.9439e-14`、`9.9616e-14`，均满足原 `1e-13` 门槛。
验证器未修改，均比较同配置；这些是实现回归，不是新增的
Aphros 稳态或空间收敛证明。

GPU 完整黏性 64 的两步运行峰值工作集由 765620224 B 降到
738959360 B，约减少 3.5%；峰值提交内存由 1350672384 B 降到
1325322240 B。存在同时运行的其他应用，这里不声称独占性能
加速，也不将不同运行方式的峰值混为一谈。

## 实际 128 构造检查

另在实际原生 128 网格上完成完整算子初始化，不推进流动。
包含 790216 个流体单元、2431944 个面、49152 个压力粗细交界面。
新旧六份初始化输出逐字节一致：单元、面、嵌入算子检查、交界
检查及两份材料探针。该检查等待全部小网格回归完成且没有其他
原生 GPU 实验，再在实际启动前重新检查可用内存。

| 同范围构造观察 | 旧版 | 新版 |
| --- | --- | --- |
| 峰值工作集 | 2771595264 B | 2593988608 B |
| 峰值提交内存 | 4332564480 B | 4137938944 B |

分别下降 6.41% 和 4.49%。本次新增阶段
`projection.gpu_host_operators_ready` 前后，实际工作集从
1933230080 B 降至 1754705920 B。最终总体峰值仍出现在原生 GPU
字段初始化阶段。启动时可用内存为 7870566400 B，运行未触发
资源停止。此结果不证明完整 256 流场可以装入当前内存。
