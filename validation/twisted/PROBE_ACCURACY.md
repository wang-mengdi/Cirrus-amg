# 曲面取样与离散壁面变化的区分

现有跨网格检查使用固定物理探针和二次最小二乘插值，分别选取
32、64 个邻居。新增诊断保持该取样程序、真实场量及全部验收门槛
不变，分别输入光滑解析壁面剪切、已有的离散壁面算子重放结果，
以及实际 CFD 剪切。它用于定位取样敏感性的来源，不是新的流动验收。

解析速度仍为既有壁面审计中的无散度、无滑移场；它并非本算例
恒定体力驱动的 Navier–Stokes 解。解析牵引同时由闭式公式和完整
牛顿应力张量核对。壁面点使用原审计的同 x、同极角映射约定。

| 网格 | 光滑解析剪切的邻居敏感性 | 离散算子重放的邻居敏感性 | 实际 CFD 剪切的邻居敏感性 |
|---|---:|---:|---:|
| 32 | 0.004862% | 0.64967% | 0.79092% |
| 64 | 0.000496% | 0.95390% | 0.87939% |
| 128 | 0.0000705% | 0.49676% | 0.62814%（瞬态） |

这里的敏感性是同一场选取 32 与 64 个邻居所得值的相对 L2 差，
并非对真实误差的上界。128 的实际 CFD 场来自已完成的 t=0.01
第二步，不能作为定常细网格对照。

对光滑解析牵引，原 32 邻居取样相对于解析探针真值的误差分别为
0.01215%、0.002801%、0.000706%。离散算子重放后的对应误差则为
7.844%、4.998%、2.104%。因此，单纯的光滑场插值误差不足以解释
实际剪切场约 0.6–0.9% 的取样敏感性，也没有依据通过更换插值器
使原有空间验收变为通过。

进一步对既有壁面误差分解施加同一个线性取样操作，分解的向量和
重放通过。在 64/128 网格中，离散壁面位置及法向到解析壁面的
转换项，其取样变化 RMS 分别为解析剪切 RMS 的 0.9321%/0.4703%；
拟合及单边导数项为 0.2692%/0.1309%。这些向量项可能互相抵消，
不能把 RMS 直接相加，也不能将制造场的分解解释成真实 CFD 误差
的精确归因。证据支持继续检查壁面几何与导数离散。

体探针也用解析速度检查。例如距壁 1.953125 mm 时，32/64/128
网格的 32 邻居插值误差分别为 0.06645%、0.007639%、0.000722%。
周期一致的 Cartesian 二次多项式重现误差最大为 2.56e-15。
32/64 实际场的原取样敏感性全部重现，指标差最大 3.13e-17，
原来的空间验收失败结论保持不变。

复现命令：

```text
python scripts/audit_twisted_probe_accuracy.py --wall-audit output/twisted/wall_accuracy32_64_128_v2 --refinement output/twisted/projection_grid32_64_steady_v3/refinement.json --output <新的D盘诊断目录>
```

JSON 保存全部距壁位置、条件数、来源哈希和历史程序快照的定位；
CSV 保存每个壁面探针的解析值及六组场量的两种邻居取样结果。
没有修改 Aphros 方程、Cirrus 求解器或跨网格取样算法。
