# 逐面构造切割边界算子

`simple/EmbeddedOperators.cpp` 将四类面系数的组装改为两次遍历：先用
原公式统计非零项数，再按原面顺序写入精确预分配的压缩行存储。
每次只保留一个面的可编辑行，不再为每个面长期保留多个 `vector`
及其独立堆分配。第二次遍历检查写入项数与第一次统计一致。

插值、面梯度、壁面梯度及对流采样的公式保持不变；每个单元的黏性
系数仍按原面顺序累计。后续单元方向梯度读取已经构造好的面梯度，
不再保留另一套面行。压缩时省略的显式零项不参与累计；全系数对照
用于验证这一变化没有改变输出。重分配和对流算子公式没有修改。

本次修改的是 CPU 初始化存储，不改变 GPU 压力/黏性算子，也不意味着
已经消除全部 CPU 显式矩阵。单元组装行和后续矩阵仍需进一步降低峰值。
网格、曲面几何、壁面加密、物性、时间步和数值验收门槛均未调整。

## 系数与流动验证

`validation/embedded_operator_stream_test.cpp` 读取已保存的真实原生
网格，结合原 Aphros 几何恢复准确的切割标志和壁面法向；不另分配
GPU 网格。同一测试程序分别链接旧、新 `EmbeddedOperators`，比较
全部稀疏矩阵的维度、行指针、列号和值，以及边界权重和检查报告。

CPU 探针使用相同的 MinGW/Eigen 5.0.1、`-O0`、关闭向量化/并行的
编译设置。16 级覆盖三个布尔选项的八种组合，64 级覆盖投影、隐式
扩散重分配、隐式对流和显式对流四种模式。全部 12 组通过，156 份
系数/检查文件逐字节一致。64 级实际有 136632 个流体单元、421004
个面、1536 个粗细交界面和 21816 个曲面壁面。

这些 CPU 探针之外，正式 MSVC/CUDA 构建也分别完成 CPU 16、GPU 16
及自适应 GPU 64 的两个物理步：

| 回归 | 实际结果 |
| --- | --- |
| CPU 16 | 最终及中间 CSV 逐字节相同 |
| GPU 16 | 五类场量最大相对 L2 差 `2.37706e-16` |
| GPU 64 | 五类场量最大相对 L2 差 `1.14552e-14` |

五类量为速度、压力、切割单元速度、壁面剪切和共享面通量。质量守恒、
完整内迭代固定点与所有线性精度检查均按原门槛通过。源码范围检查
单独验证了曲面、粗细交界公式及原累加顺序，不能替代上述数值执行。
