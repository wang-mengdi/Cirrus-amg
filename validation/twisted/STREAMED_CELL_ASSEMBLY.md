# 逐单元构造切割边界算子

在逐面压缩之后，`simple/EmbeddedOperators.cpp` 进一步取消全网格的
可编辑黏性行及方向梯度行。先完成面算子和原重分配算子，释放几何
邻域工作区，再利用紧凑的单元—面邻接表逐单元生成压缩行。

邻接表按原始面 ID 顺序填充，正负编号区分 owner/neighbor；若同一
单元同时是两侧，仍先累计 owner，再累计 neighbor。这样每个单元的
浮点累计顺序与旧版逐面循环一致。黏性与方向梯度均先统计非零项，
再精确预分配并写入；每次只保留一个单元的可编辑行。

面插值、曲面法向梯度、二次粗细交界重构、重分配和对流公式保持
不变。几何、壁面加密、物性、时间步、GPU 算子与误差门槛未调整。
这是 CPU 初始化存储优化，仍保留后续 CPU 显式算子和 GPU 面算子。

## 实际验证

CPU 独立探针分别链接改前、改后的源文件，读取同一份真实原生
切割网格。16 级覆盖全部八种算子选项组合，64 级覆盖四种物理模式。
12 组全部通过，156 份稀疏系数、边界权重与守恒/解析检查文件逐字节
相同。测试程序及输入格式沿用 `validation/embedded_operator_stream_test.cpp`。

正式 MSVC/CUDA 程序完成两个物理步的回归：

| 回归 | 结果 |
| --- | --- |
| CPU 16 | 最终及中间 CSV 逐字节相同 |
| GPU 16 | 五类场量最大相对 L2 差 `2.25698e-16` |
| GPU 64 | 五类场量最大相对 L2 差 `1.19106e-14` |

五类场量为速度、压力、切割单元速度、壁面剪切、共享面通量。完整
内迭代固定点、质量守恒与所有 GPU 线性残差均通过原门槛。这些结果
证明本次存储修改的回归一致性，不替代独立 Aphros 或空间收敛验证。

源码范围检查 v1 因定位标记不唯一失败，未执行物理测试；v2 将标记
定位到构造函数后通过。两版脚本和失败记录均保留，不覆盖失败证据。
