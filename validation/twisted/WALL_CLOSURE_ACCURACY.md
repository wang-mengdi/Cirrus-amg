# 现有三维曲面壁面处理的一阶精度

本次独立解析场诊断确认：当前沿用 Aphros 的线性壁面拟合，连同
现有切割几何，在扭曲管道上给出的面积加权壁面剪切误差约按一阶
下降。它揭示了空间精度来源，没有改变求解器、参考算法或既有
物理验收门槛，也没有把一个解析算子检查替代真实管流求解。

## 已实际重放 C++ 输出

输入几何来自以下已经完成的运行：32 与 64 网格的定常末步，以及
128 网格两步恢复验证的第二步。128 在此只提供实际几何与已保存
算子作用，未被当作定常解。

诊断先用各自的真实 u 重放 C++ 壁面导数和剪切：三维 3×3×3 流体
邻域、无权重仿射拟合、在 `wall_center - h*normal` 处求值，并以
零壁面速度形成单边差分。每个壁面有 11–26 个有效邻居，局部
法方程的最大条件数为 15.23 以下。与实际 C++ QR 输出比较，导数
最大缩放差为 1.16e-15，剪切也通过 1e-11 重放检查。

这与 `simple/EmbeddedOperators.cpp` 的壁面分支一致。Aphros
`src/solver/approx_eb.ipp` 中 `GradDirichletLinearFit` 的原文注释
明确写明一阶，`UEmbed::Gradient` 的 Dirichlet 分支实际调用它。
源码也有被注释的其他候选调用，但本轮没有修改该选择。不能把
后处理中增加拟合次数或提高插值阶数当作已修正求解器的壁面算子。

## 解析速度及剪切

沿用真实算例的解析中心线、半径和周期，定义：

```
Y = y - yc(x), Z = z - zc(x)
u = U * (1 - (Y^2 + Z^2)/R^2) * (1, yc'(x), zc'(x))
U = 0.02 m/s
```

该场满足 div(u)=0，在解析曲面 Y²+Z²=R² 上为零，并沿 x 周期。
它不是恒定体力原算例的解；这里只将它代入现有壁面算子，分析
已知精确导数的误差。

每个离散壁面中心按相同 x 和中心线周围极角映射到解析曲面。
记 `s=yc'*cos(theta)+zc'*sin(theta)`，解析切向牵引为：

```
tau = -2*mu*U/R * sqrt(1+s^2) * (1, yc', zc')
```

脚本还独立计算完整对称速度梯度应力在解析壁面上的切向分量，
与该闭式表达式核对；同时检查解析散度与无滑移条件。
这里的牵引方向与已有 `WallShear` 导出约定一致。

## 测得的空间误差

| 最细 ny | 壁面数 | 面积加权相对 L2 | 按壁面面积统计的 95% 误差分位 |
|---|---:|---:|---:|
| 32 | 5424 | 7.78537% | 10.8605% |
| 64 | 21816 | 3.86218% | 5.44714% |
| 128 | 87248 | 1.93935% | 2.71501% |

相邻加密的绝对 L2 误差阶分别为 1.0113 和 0.9938。
这些误差包含在离散平面施加零速度、壁面拟合/单边差分，以及
离散位置和法向到解析壁面的几何差异。

诊断按向量恒等式将三部分分开记录。128 网格中三项相对 RMS
分别约为 0.4284%、2.2980%、0.3115%；它们会相互抵消，不能把
三个 RMS 直接相加来得到总误差。主导项是拟合与单边导数这一项。

面积平均的下降没有消除所有局部偏差。128 网格最大逐面相对误差
为 70.4812%，超过 25% 的面占总壁面面积约 0.0052893%；与解析
法向夹角超过 5° 的面占约 0.0090281% 的壁面面积，贡献约 2.1402%
的剪切误差能量。这些局部统计均为描述量，没有新增或放宽物理
验收标准，也没有删除极小面。

## 固定探针处的采样敏感性诊断

补充检查将误差追踪到现有壁面算子，而没有修改后处理或验收门槛。
首先确认空间检查已经沿解析壁面的两个切向做二次拟合，局部条件数
约为 8，常数场的重现误差低于 1e-12。使用相同的离散壁面中心、
相同的 128 个解析探针和相同拟合函数，对已知精确值的光滑切向场
做检查，128 网格的插值相对 L2 误差约为 7.35e-6。

然后复用此前已经重放 C++ 输出的解析速度场壁面审计。新检查逐面
验证其面编号、壁面位置和面积与当前 64/128 定常输出相符，再分别
对精确剪切、经现有壁面算子得到的剪切、实际管流剪切做同样采样。
将邻居数从 32 改为 64，所得相对 L2 变化为：

| 最细 ny | 精确壁面场 | 解析速度经现有壁面算子 | 实际管流壁面输出 |
|---|---:|---:|---:|
| 64 | 0.0004957% | 0.9539% | 0.8794% |
| 128 | 0.00007049% | 0.4968% | 0.4721% |

后两种采样变化的面积权重向量余弦分别为 0.974 和 0.966。这支持
已有壁面离散误差主导该敏感性的判断；不是对真实恒定体力解误差的
严格分解。诊断中的拟合比例仅用于解释相关性，没有用于修正、缩放
或替代真实输出。将邻居数继续增至 128，也没有消除解析算子的真实
误差：128 网格在固定探针处仍约为 2.1%–2.3%。

因此不通过选择一个更平滑的邻居数让检查变绿。原有 0.25% 采样
敏感性门槛、1% 剪切网格差门槛以及近壁速度要求保持不变，继续
等待真实 256 网格定常结果并做同一套空间比较。

可复现证据在 `results/wall_sampling_diagnostic/receipt.json`；完整
诊断输出在 `D:/CirrusExperiments/cirrus-amg/checks/` 下的
`twisted_wall_sampling_diagnostic_v1`、`twisted_wall_closure_sampling_v1`
和 `twisted_wall_sampling_plot_v2`。两类诊断都不宣称独立 Aphros

## 256 几何与壁面面积权重的补充诊断

分批几何检查把同一制造解扩展到现有 256 几何，峰值工作集约 247 MiB。
128 重算与此前已经重放 C++ 输出的剪切值相差 2.84e-16；256 检查还逐一
确认所有壁面拟合所需的流体细单元均存在于当前原生八叉树。没有运行新的
256 流场，也没有声称已检查 256 的实际 C++ 壁面导数。

| 最细 ny | 整片壁面面积加权误差 | 原探针误差（32 邻点） | 面积加权候选探针误差 |
|---|---:|---:|---:|
| 128 | 1.9394% | 2.1043% | 1.8416% |
| 256 | 0.9970% | 4.3911% | 0.9318% |

整片壁面误差下降，但原采样的 32/64 邻点敏感性从 0.4968% 上升至
1.7346%。256 中面积小于 0.01 h² 的面占面数 4.5775%，只占壁面面积
0.02579%，法向与解析法向的最大夹角约 51.93°。原拟合的距离权重没有
包含面片面积，极小面可能对探针产生过大的贡献。这进一步细化了前一节
的判断：壁面离散会产生异常值，采样的表面测度也会放大其影响。

所检查的 Aphros `src/solver/embed.ipp` 先将切割网格面开口面积截断到
[0.001, 0.999] 倍完整面面积，再通过这些面积的向量和构造切割壁面法向。
这提供了理解极小面法向偏差的实现依据；本次没有更改原 Aphros 几何或算法。

新增 `scripts/twisted_wall_sampling_candidate.py` 仅供诊断。它保留原探针、
邻域、切向二次基函数与距离核，将残差平方的权重乘以正的壁面片面积。
没有删除小面，也没有缩放真实剪切场。二次场重现、等面积时与原拟合等价、
将每个面分成两个同位置半面积样本的不变性、统一缩放面积的不变性均通过，
误差不超过 1.34e-15。制造解的 256 采样敏感性降至 0.03237%。

对已经完成的真实 64/128 定常场使用该候选，32/64 邻点敏感性分别为
0.26890% 和 0.11565%；64→128 的剪切差为 0.34198%，原方法为 1.9673%。
64 的采样差仍超过原 0.25% 门槛。流量差和近壁速度失败项没有改变。
这些结果没有被用于替换正式验收；原检查器及原失败报告保持不变。

证据在 `results/wall_geometry256_sampling/receipt.json`。完整的几何逐面数据
