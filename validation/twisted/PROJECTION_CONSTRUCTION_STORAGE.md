# 释放投影求解器的构造期存储

`simple/ProjectionSolver.cpp` 现在在最后一次使用后释放构造数据：

- 装配压力、法向梯度和粗细界面 Taylor 算子后，销毁原始 triplet、
  插值检查向量和临时修正矩阵。
- 算子已经拥有重构权重后，释放二次重构缓存。
- 已生成带物性系数的黏性矩阵后，释放其未缩放副本；材料探针的
  临时场在导出完成后释放。
- 仅在 CPU 分支构造带压力固定点的矩阵和隐式黏性线性系统。
  GPU 分支继续使用原生八叉树算子和 AMG，不再构造这两个未使用
  的 CPU 系统。

保留了离散系数、装配次序、迭代算法、边界条件和全部收敛门槛。
CPU 侧仍有用于输运、压力修正及残差检查的显式算子；本改动没有
完成整个 CPU 数据路径的 matrix-free 化。

实测没有降低峰值。这里没有把释放的数据字节数等同于操作系统
立即回收的字节数，也没有把提交内存计数当作实际磁盘写入量。

声明独占性能提升。

这些是两步回归和内存测量，不能证明 128/256 的内存峰值，也不
证明定常或空间精度。已完成的原生 128 定常解、独立 Aphros 128
参考和 [64→128 空间验收失败](SPATIAL_CONVERGENCE_64_128.md)保持
各自的验证范围。本改动不替代后续更细网格和近壁精度检查。
