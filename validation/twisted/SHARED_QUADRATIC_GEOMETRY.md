# 共享完全相同的二次重构几何

二次重构的系数只依赖单元尺寸和有序样本位移。原先每个活跃
单元分别保留所有位移和系数，即使这些输入完全相同，也重复
求 QR/SVD 并存储相同数据。本版在一次网格构造内共享相同模板，
每个单元只保留自己的样本单元编号和模板索引。

`simple/QuadraticReconstruction.cpp` 的键包含 `h` 和按原样本顺序
排列的全部三维位移，逐个复制 double 的 64 位表示。使用完整
键比较，保留正负零，不量化、不重新排序，也不跨单元尺寸共享。
首次遇到模板时执行原来的加权设计矩阵、QR/SVD、尺度变换及
合法性检查；后续单元使用同一份系数和位移。临时查找键在构造
结束后释放，模板随重构对象释放。

样本单元编号始终属于各自单元。导数行仍按原样本顺序累加，
场量求值仍执行原矩阵向量乘法；解析测试仍在原周期展开坐标
求值。所有公共接口和面公式不变。这里的 QR/SVD 是九列局部
最小二乘重构，不是压力投影系统的全局分解。
